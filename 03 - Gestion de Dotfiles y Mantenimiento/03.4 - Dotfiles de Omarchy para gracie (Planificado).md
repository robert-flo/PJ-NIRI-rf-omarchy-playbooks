## 🛠️ Uso diario

Igual que en [[03.1 - Dotfiles con dotbare|03.1]]: `export DOTBARE_DIR="$HOME/.cfg" DOTBARE_TREE="$HOME"` (ya en `~/.bashrc`), y cada cambio por rama auxiliar + PR a `master`:

```bash
dotbare checkout -b ajuste/x
dotbare fadd && dotbare commit -m "..."
dotbare push -u origin ajuste/x
gh pr create --repo robert-flo/sura-home --base master --head ajuste/x
```

**Restaurar en otra PC** (como `gracie`): `dotbare finit -u git@github.com:robert-flo/sura-home.git`, después el arreglo de refspec/upstream de [[03.1 - Dotfiles con dotbare|03.1, sección 0]] y `hyprctl reload` + `hyprctl configerrors`. El procedimiento completo de recuperación es el Capítulo 8 del playbook PJ-LARRY.
