# 🎨 Personalización MacTahoe: Iconos, Cursor, Wallpaper y Temas GTK

> [!NOTE]
> **Navegación:**
> * Anterior: [[01.3 - Paso 3 - Clavis Shell y Actualizaciones|Paso 3: Clavis Shell y Actualizaciones]]
> * Siguiente: [[02.2 - Replicacion de Aplicaciones y Entorno Clavis|Replicación de Aplicaciones y Entorno Clavis]]
> * Volver a: [[00 - Indice General (MOC)|Índice General]]

Esta guía detalla la instalación global y configuración del conjunto estético **MacTahoe** (iconos, cursores y tema GTK) junto con el wallpaper oficial de Wallhaven, garantizando compatibilidad tanto en sesiones **Niri** (con Clavis Shell) como en sesiones **Hyprland** (Omarchy).

---

## 🎯 Resumen de Configuración

| Elemento | Valor Seleccionado | Destino en el Sistema |
|---|---|---|
| **Tema de Iconos** | `MacTahoe-dark` | `/usr/share/icons/MacTahoe-dark` |
| **Tema de Cursor** | `MacTahoe-dark-cursors` | `/usr/share/icons/MacTahoe-dark-cursors` |
| **Tamaño de Cursor** | `24` | GTK, Niri y Hyprland |
| **Wallpaper** | `wallhaven-5y3571.jpg` (3840×1634) | `/usr/share/backgrounds/wallhaven-5y3571.jpg` |
| **Tema GTK3 / GTK4** | `MacTahoe-Dark` | `/usr/share/themes/MacTahoe-Dark` |

---

## 1️⃣ Instalación Global de Iconos y Cursores

Instalar de forma global en `/usr/share/icons` para que cualquier usuario del sistema tenga acceso a los recursos:

```bash
cd /tmp
git clone --depth 1 https://github.com/vinceliuice/MacTahoe-icon-theme.git
cd MacTahoe-icon-theme

# 1. Instalar iconos en /usr/share/icons (MacTahoe, MacTahoe-light, MacTahoe-dark)
sudo ./install.sh -d /usr/share/icons

# 2. Instalar cursores (como root se instalan automáticamente en /usr/share/icons)
cd cursors
sudo ./install.sh

# 3. Limpiar directorio temporal
cd /tmp && rm -rf MacTahoe-icon-theme
```

**Verificación:**
```bash
ls -d /usr/share/icons/MacTahoe*
# Salida esperada: MacTahoe  MacTahoe-dark  MacTahoe-dark-cursors  MacTahoe-light  MacTahoe-cursors
```

## 2️⃣ Activación en Hyprland (Usuario Principal / Omarchy)

Si utilizas Hyprland u Omarchy en paralelo:

### 2.1 Configuración GTK mediante GSettings
```bash
gsettings set org.gnome.desktop.interface icon-theme 'MacTahoe-dark'
gsettings set org.gnome.desktop.interface cursor-theme 'MacTahoe-dark-cursors'
gsettings set org.gnome.desktop.interface cursor-size 24
```

### 2.2 Cursor persistente en `~/.config/hypr/hyprland.lua`
```lua
hl.env("XCURSOR_THEME", "MacTahoe-dark-cursors")
hl.env("XCURSOR_SIZE", "24")
```

Aplicar en caliente:
```bash
hyprctl reload
hyprctl setcursor MacTahoe-dark-cursors 24
```

### 2.3 Fallback para apps XWayland
```bash
mkdir -p ~/.icons/default
printf '[Icon Theme]\nInherits=MacTahoe-dark-cursors\n' > ~/.icons/default/index.theme
```

## 3️⃣ Activación en Niri (Usuario Dedicado / Clavis)

En el entorno Niri, Clavis gestiona dinámicamente ciertas variables, pero es fundamental establecer el cursor del compositor y las preferencias de GSettings:

```bash
TARGET_USER="${1:-niri}"
TARGET_UID="$(id -u "$TARGET_USER")"
TARGET_HOME="$(getent passwd "$TARGET_USER" | cut -d: -f6)"

sudo -u "$TARGET_USER" env DBUS_SESSION_BUS_ADDRESS="unix:path=/run/user/$TARGET_UID/bus" bash -c "
# 1. GSettings de iconos y cursores
gsettings set org.gnome.desktop.interface icon-theme 'MacTahoe-dark'
gsettings set org.gnome.desktop.interface cursor-theme 'MacTahoe-dark-cursors'
gsettings set org.gnome.desktop.interface cursor-size 24

# 2. Fallback de iconos XWayland
mkdir -p '$TARGET_HOME/.icons/default'
printf '[Icon Theme]\nInherits=MacTahoe-dark-cursors\n' > '$TARGET_HOME/.icons/default/index.theme'

# 3. Regla propia de cursor en Niri (evita sobrescritura de Clavis)
printf 'cursor {\n    xcursor-theme \"MacTahoe-dark-cursors\"\n    xcursor-size 24\n}\n' > '$TARGET_HOME/.config/niri/cursor-theme.kdl'

# 4. Incluir cursor-theme.kdl al final de config.kdl
grep -q 'cursor-theme.kdl' '$TARGET_HOME/.config/niri/config.kdl' || printf '\ninclude \"cursor-theme.kdl\";\n' >> '$TARGET_HOME/.config/niri/config.kdl'

# 5. Validar sintaxis
niri validate -c '$TARGET_HOME/.config/niri/config.kdl'
"
```

> [!TIP]
> Al incluir `cursor-theme.kdl` al final de `config.kdl`, se asegura prioridad sobre cualquier valor predeterminado.

## 4️⃣ Descarga y Aplicación de Wallpaper

### 4.1 Descarga a nivel global
Descargar el fondo oficial [Wallhaven 5y3571](https://wallhaven.cc/w/5y3571) a `/usr/share/backgrounds/`:

```bash
sudo mkdir -p /usr/share/backgrounds
sudo curl -sL -o /usr/share/backgrounds/wallhaven-5y3571.jpg https://w.wallhaven.cc/full/5y/wallhaven-5y3571.jpg
sudo chmod 644 /usr/share/backgrounds/wallhaven-5y3571.jpg
```

### 4.2 Configuración para Clavis Shell (Niri)
Clavis almacena sus wallpapers en `~/.local/share/clavis/wallpapers` y lee la ruta desde `~/.config/clavis/config.json`:

```bash
sudo -u "$TARGET_USER" bash -c "
mkdir -p '$TARGET_HOME/.local/share/clavis/wallpapers' '$TARGET_HOME/.config/clavis'
cp /usr/share/backgrounds/wallhaven-5y3571.jpg '$TARGET_HOME/.local/share/clavis/wallpapers/'

# Si config.json no existe o es nuevo:
if [ ! -f '$TARGET_HOME/.config/clavis/config.json' ]; then
    cat > '$TARGET_HOME/.config/clavis/config.json' <<EOF
{
  \"wallpaper\": {
    \"folder\": \"$TARGET_HOME/.local/share/clavis/wallpapers\",
    \"path\": \"$TARGET_HOME/.local/share/clavis/wallpapers/wallhaven-5y3571.jpg\"
  }
}
EOF
else
    # Si ya existe, actualizar solo las claves de wallpaper con Python
    python3 -c \"
import json
p = '$TARGET_HOME/.config/clavis/config.json'
with open(p, 'r') as f: d = json.load(f)
d.setdefault('wallpaper', {})['folder'] = '$TARGET_HOME/.local/share/clavis/wallpapers'
d['wallpaper']['path'] = '$TARGET_HOME/.local/share/clavis/wallpapers/wallhaven-5y3571.jpg'
with open(p, 'w') as f: json.dump(d, f, indent=2)
\"
fi
"
```

Si la sesión de Niri está activa, puede aplicarse de inmediato vía IPC:
```bash
qs -c clavis ipc call wallpaper set "$TARGET_HOME/.local/share/clavis/wallpapers/wallhaven-5y3571.jpg"
```

## 5️⃣ Tema GTK MacTahoe (Global, GTK3 y GTK4)

> [!WARNING]
> **Precaución con el instalador de MacTahoe GTK en Arch:**
> El script oficial de instalación comprueba la presencia de `sassc`, `glib-compile-resources` y `xmllint`. Si alguna falta, ejecutará `sudo pacman -Syyu --noconfirm`, forzando una actualización no planificada del sistema. Instala `sassc` previamente:
> ```bash
> sudo pacman -S --needed sassc
> ```

### 5.1 Instalación global del tema GTK
```bash
cd /tmp
git clone --depth 1 https://github.com/vinceliuice/MacTahoe-gtk-theme.git
cd MacTahoe-gtk-theme
sudo ./install.sh -d /usr/share/themes
```

### 5.2 Configuración para el usuario Niri
Activar el tema oscuro en GTK3/GTK4 y definir botones estilo macOS a la izquierda (`close,minimize,maximize:`):

```bash
sudo -u "$TARGET_USER" env DBUS_SESSION_BUS_ADDRESS="unix:path=/run/user/$TARGET_UID/bus" bash -c "
gsettings set org.gnome.desktop.interface gtk-theme 'MacTahoe-Dark'
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
gsettings set org.gnome.desktop.wm.preferences button-layout 'close,minimize,maximize:'

# Configuración settings.ini para compatibilidad con aplicaciones antiguas
for v in 3.0 4.0; do
    mkdir -p \"\$HOME/.config/gtk-\$v\"
    cat > \"\$HOME/.config/gtk-\$v/settings.ini\" <<EOF
[Settings]
gtk-theme-name=MacTahoe-Dark
gtk-icon-theme-name=MacTahoe-dark
gtk-cursor-theme-name=MacTahoe-dark-cursors
gtk-cursor-theme-size=24
gtk-application-prefer-dark-theme=1
gtk-decoration-layout=close,minimize,maximize:
EOF
done
"

# Integración libadwaita (GTK4): requiere ejecutarse con el $HOME del usuario objetivo
cp -r /tmp/MacTahoe-gtk-theme /tmp/mactahoe-user
sudo chown -R "$TARGET_USER:$TARGET_USER" /tmp/mactahoe-user
sudo -u "$TARGET_USER" -H bash -c '
cd /tmp/mactahoe-user
./install.sh -l -c dark -d /tmp/discard
rm -rf /tmp/discard
rm -f ~/.local/bin/gnome-theme-switcher ~/.local/share/applications/org.gnome.GTK4ThemeSwitcher.desktop
'
sudo rm -rf /tmp/mactahoe-user /tmp/MacTahoe-gtk-theme
```
