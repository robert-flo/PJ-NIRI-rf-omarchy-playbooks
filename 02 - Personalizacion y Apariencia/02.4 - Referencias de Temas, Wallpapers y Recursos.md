## 🛠️ Comandos de Descarga Rápida

```bash
# Descarga del wallpaper principal (requiere curl)
sudo mkdir -p /usr/share/backgrounds
sudo curl -sL -o /usr/share/backgrounds/wallhaven-5y3571.jpg https://w.wallhaven.cc/full/5y/wallhaven-5y3571.jpg
sudo chmod 644 /usr/share/backgrounds/wallhaven-5y3571.jpg

# Descarga del wallpaper alternativo
sudo curl -sL -o /usr/share/backgrounds/wallhaven-rq6yqm.jpg https://w.wallhaven.cc/full/rq/wallhaven-rq6yqm.jpg
sudo chmod 644 /usr/share/backgrounds/wallhaven-rq6yqm.jpg
```
