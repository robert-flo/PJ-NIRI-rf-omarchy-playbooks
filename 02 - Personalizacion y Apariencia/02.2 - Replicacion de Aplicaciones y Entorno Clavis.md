# 🖥️ Replicación de Aplicaciones y Entorno Clavis

> [!NOTE]
> **Navegación:**
> * Anterior: [[02.1 - MacTahoe Iconos, Cursor y Wallpapers|Personalización MacTahoe y Wallpapers]]
> * Siguiente: [[02.3 - Tipografias y Fuentes del Sistema|Tipografías y Fuentes del Sistema]]
> * Volver a: [[00 - Indice General (MOC)|Índice General]]

Este playbook documenta la integración minuciosa de aplicaciones y módulos complementarios creados por el autor de Clavis ([StatIndet](https://github.com/StatIndet)), logrando la estética "Liquid Glass / macOS" con animaciones fluidas, difuminado Wayland (*blur*), botones semáforo integrados y esquemas de color dinámicos generados por Matugen.

---

## 🧩 Componentes del Entorno

| Componente | Repositorio Oficial | Rol |
|---|---|---|
| **mpv Cupertino** | [StatIndet/mpv](https://github.com/StatIndet/mpv) | Interfaz uosc 5.13.0 modificada con botones tipo macOS, miniaturas y aceleración por GPU. |
| **Obsidian Violet** | [StatIndet/obsidian-violet](https://github.com/StatIndet/obsidian-violet) | Tema CSS nativo con esquinas redondeadas, tarjetas opacas y blur vía Niri. |
| **LiquidBird** | [StatIndet/liquidbird](https://github.com/StatIndet/liquidbird) | Tema CSS para Thunderbird con barra lateral translúcida y botones MacTahoe. |
| **Botones macOS** | Temas por aplicación + GTK | Control unificado de ventana (`close,minimize,maximize:`). |
| **fcitx5-matugen** | [StatIndet/fcitx5-matugen-theme](https://github.com/StatIndet/fcitx5-matugen-theme) | Método de entrada cuyos paneles adoptan los colores del wallpaper. |
| **clavis-fish-theme** | [StatIndet/clavis-fish-theme](https://github.com/StatIndet/clavis-fish-theme) | Shell interactiva con prompt en cápsulas Material 3 vinculada al wallpaper. |

## 1️⃣ mpv "Cupertino" (uosc Personalizado)

Configura mpv con botones semáforo flotantes, barra de tiempo interactiva, miniaturas de video y velocidad 2× temporal manteniendo pulsada la flecha derecha.

### 1.1 Instalación y Ajuste de Aceleración por GPU
```bash
TARGET_USER="${1:-niri}"
TARGET_HOME="$(getent passwd "$TARGET_USER" | cut -d: -f6)"

cd /tmp
git clone --depth 1 https://github.com/StatIndet/mpv.git statindet-mpv

sudo -u "$TARGET_USER" bash -c "
mkdir -p '$TARGET_HOME/.config/mpv' '$TARGET_HOME/Pictures/mpv'
cp -r /tmp/statindet-mpv/{fonts,input.conf,mpv.conf,script-opts,scripts} '$TARGET_HOME/.config/mpv/'

# Adaptación automática del decodificador por hardware (hwdec)
# Si es Intel o AMD -> vaapi; si es NVIDIA -> nvdec
if lspci | grep -Ei 'vga|3d' | grep -iq 'nvidia'; then
    sed -i 's/^hwdec=.*/hwdec=nvdec/' '$TARGET_HOME/.config/mpv/mpv.conf'
else
    sed -i 's/^hwdec=.*/hwdec=vaapi/' '$TARGET_HOME/.config/mpv/mpv.conf'
fi
"
rm -rf /tmp/statindet-mpv
```

### 1.2 Descarga del Ayudante `ziggy-linux` (Subtítulos uosc)
```bash
cd /tmp
curl -sL -o uosc-5.13.0.zip https://github.com/tomasklaen/uosc/releases/download/5.13.0/uosc.zip
unzip -q uosc-5.13.0.zip "scripts/uosc/bin/ziggy-linux" -d uosc-rel
sudo -u "$TARGET_USER" install -Dm755 uosc-rel/scripts/uosc/bin/ziggy-linux \
  "$TARGET_HOME/.config/mpv/scripts/uosc/bin/ziggy-linux"
rm -rf uosc-5.13.0.zip uosc-rel
```

## 2️⃣ Tema de Obsidian "Violet" y Reglas de Desenfoque

### 2.1 Despliegue del Tema y Vault de Notas
```bash
cd /tmp
git clone --depth 1 https://github.com/StatIndet/obsidian-violet.git

sudo -u "$TARGET_USER" bash -c "
V='$TARGET_HOME/Documents/Notas'
mkdir -p \"\$V/.obsidian/themes/Violet\" \"\$V/.obsidian/snippets\"
cp /tmp/obsidian-violet/manifest.json /tmp/obsidian-violet/theme.css \"\$V/.obsidian/themes/Violet/\"
cp /tmp/obsidian-violet/integration/native-glass.css \"\$V/.obsidian/snippets/violet-native-glass.css\"

cat > \"\$V/.obsidian/appearance.json\" <<JSON
{
  \"cssTheme\": \"Violet\",
  \"theme\": \"obsidian\",
  \"enabledCssSnippets\": []
}
JSON
printf '# Notas\n\nVault con tema Violet y compatibilidad Clavis.\n' > \"\$V/Bienvenida.md\"

# Registrar vault en ~/.config/obsidian/obsidian.json si no existe
if [ ! -f '$TARGET_HOME/.config/obsidian/obsidian.json' ]; then
    mkdir -p '$TARGET_HOME/.config/obsidian'
    ID=\$(head -c 8 /dev/urandom | od -An -tx1 | tr -d ' \n')
    TS=\$(date +%s%3N)
    cat > '$TARGET_HOME/.config/obsidian/obsidian.json' <<JSON
{
  \"vaults\": {
    \"\$ID\": { \"path\": \"$TARGET_HOME/Documents/Notas\", \"ts\": \$TS, \"open\": true }
  }
}
JSON
fi
"
```

### 2.2 Regla Wayland en Niri para Obsidian (Esquinas Redondeadas y Blur)
```bash
sudo -u "$TARGET_USER" bash -c "
cp /tmp/obsidian-violet/integration/niri.kdl '$TARGET_HOME/.config/niri/obsidian-violet.kdl'
grep -q 'obsidian-violet.kdl' '$TARGET_HOME/.config/niri/config.kdl' || \
  printf '\ninclude \"obsidian-violet.kdl\";\n' >> '$TARGET_HOME/.config/niri/config.kdl'
niri validate -c '$TARGET_HOME/.config/niri/config.kdl'
"
rm -rf /tmp/obsidian-violet
```

## 3️⃣ Thunderbird y Tema "LiquidBird"

LiquidBird estiliza Mozilla Thunderbird transformándolo en una interfaz limpia tipo macOS con barra lateral translúcida.

### 3.1 Instalación y Empaquetado
```bash
sudo pacman -S --needed --noconfirm thunderbird

cd /tmp
git clone --depth 1 https://github.com/StatIndet/liquidbird.git
cd liquidbird
/usr/bin/python3 scripts/package_release.py --output dist
```

### 3.2 Aplicación al Perfil de Thunderbird
```bash
# Crear perfil headless si no existe
sudo -u "$TARGET_USER" env -u DISPLAY -u WAYLAND_DISPLAY bash -c "
cd ~; thunderbird --headless --CreateProfile 'default-release' || true
"

sudo -u "$TARGET_USER" bash -c "
P=\$(find '$TARGET_HOME/.config/thunderbird' -maxdepth 1 -type d -name '*.default-release*' | head -1)
if [ -z \"\$P\" ]; then
    P='$TARGET_HOME/.config/thunderbird/default-profile'
    mkdir -p \"\$P\"
fi

# Habilitar personalización de hojas de estilo
echo 'user_pref(\"toolkit.legacyUserProfileCustomizations.stylesheets\", true);' >> \"\$P/user.js\"

# Desempaquetar recursos en chrome/
T=\$(mktemp -d)
unzip -q /tmp/liquidbird/dist/LiquidBird-*.zip -d \"\$T\"
mkdir -p \"\$P/chrome\"
cp -r \"\$T/chrome/\"{liquidbird.css,liquidbird-content.css,Icons,linux,userChrome.css,userContent.css} \"\$P/chrome/\"
[ -f \"\$P/chrome/custom.css\" ] || cp \"\$T/chrome/custom.css.example\" \"\$P/chrome/custom.css\"
rm -rf \"\$T\"
"

# 3.3 Regla de desenfoque de Niri para Thunderbird
sudo -u "$TARGET_USER" bash -c "
cp /tmp/liquidbird/integration/niri.kdl '$TARGET_HOME/.config/niri/liquidbird.kdl'
grep -q 'liquidbird.kdl' '$TARGET_HOME/.config/niri/config.kdl' || \
  printf '\ninclude \"liquidbird.kdl\";\n' >> '$TARGET_HOME/.config/niri/config.kdl'
niri validate -c '$TARGET_HOME/.config/niri/config.kdl'
"
rm -rf /tmp/liquidbird
```

## 4️⃣ Integración Dinámica de Matugen (Colores Reactivos)

Clavis integra un registro dinámico en `~/.config/clavis/matugen/config.toml` para actualizar temas cada vez que cambia el fondo de pantalla:

### 4.1 Tema para Fcitx5
```bash
cd /tmp
git clone --depth 1 https://github.com/StatIndet/fcitx5-matugen-theme.git
sudo cp -r /tmp/fcitx5-matugen-theme "$TARGET_HOME/.local/share/"
sudo chown -R "$TARGET_USER:$TARGET_USER" "$TARGET_HOME/.local/share/fcitx5-matugen-theme"

sudo -u "$TARGET_USER" mkdir -p "$TARGET_HOME/.local/share/fcitx5/themes/Matugen" "$TARGET_HOME/.config/clavis/matugen"
```

Añadir al archivo `~/.config/clavis/matugen/config.toml` (usuario objetivo):

```toml
[templates.fcitx5_theme]
input_path = "~/.local/share/fcitx5-matugen-theme/templates/theme.conf"
output_path = "~/.local/share/fcitx5/themes/Matugen/theme.conf"

[templates.fcitx5_panel]
input_path = "~/.local/share/fcitx5-matugen-theme/templates/panel.svg"
output_path = "~/.local/share/fcitx5/themes/Matugen/panel.svg"
post_hook = "bash \"$HOME/.local/share/fcitx5-matugen-theme/scripts/render-panel.sh\" \"$HOME/.local/share/fcitx5/themes/Matugen/panel.svg\" \"$HOME/.local/share/fcitx5/themes/Matugen/panel.png\""

[templates.fcitx5_highlight]
input_path = "~/.local/share/fcitx5-matugen-theme/templates/highlight.svg"
output_path = "~/.local/share/fcitx5/themes/Matugen/highlight.svg"

[templates.fcitx5_radio]
input_path = "~/.local/share/fcitx5-matugen-theme/templates/radio.svg"
output_path = "~/.local/share/fcitx5/themes/Matugen/radio.svg"

[templates.fcitx5_arrow]
input_path = "~/.local/share/fcitx5-matugen-theme/templates/arrow.svg"
output_path = "~/.local/share/fcitx5/themes/Matugen/arrow.svg"
post_hook = "busctl --user call org.fcitx.Fcitx5 /controller org.fcitx.Fcitx.Controller1 ReloadAddonConfig s classicui"
```

### 4.2 Shell Fish y Prompt `clavis-fish-theme`

Instalar el generador del prompt de dos líneas con colores Material 3:

```bash
sudo pacman -S --needed --noconfirm fish

# Compilar desde el fork personal (almacenado en /opt/src o clon temporal)
cd /tmp
git clone --depth 1 -b personal https://github.com/robert-flo/PJ-NIRI-fo-clavis-fish-theme.git clavis-fish-theme
cd clavis-fish-theme && CARGO_NET_GIT_FETCH_WITH_CLI=true cargo build --release --locked
sudo install -Dm755 target/release/clavis-fish-theme /usr/local/bin/clavis-fish-theme
chmod -R a+rX /tmp/clavis-fish-theme/examples

# Configuración en el usuario (antes de borrar el clon: necesita examples/matugen.conf)
sudo -u "$TARGET_USER" bash -c "
mkdir -p '$TARGET_HOME/.local/share/clavis-fish-theme' '$TARGET_HOME/.config/clavis-fish-theme' '$TARGET_HOME/.config/fish'
cp /tmp/clavis-fish-theme/examples/matugen.conf '$TARGET_HOME/.local/share/clavis-fish-theme/matugen.conf'

# Inicializar prompt en config.fish
grep -q 'clavis-fish-theme init fish' '$TARGET_HOME/.config/fish/config.fish' 2>/dev/null || \
  printf 'if status is-interactive\n    clavis-fish-theme init fish | source\nend\n' >> '$TARGET_HOME/.config/fish/config.fish'
"
cd /tmp && rm -rf /tmp/clavis-fish-theme

# Configurar Alacritty para abrir Fish de forma interactiva (sin alterar el login shell /bin/bash).
# El alacritty.toml de Omarchy (/etc/skel) ya trae una tabla [terminal]: se inserta dentro de ella.
sudo -u "$TARGET_USER" -H /usr/bin/python3 - <<'PY'
import os, tomllib
p = os.path.expanduser("~/.config/alacritty/alacritty.toml")
if os.path.exists(p):
    s = open(p).read()
    if 'program = "/usr/bin/fish"' not in s:
        line = 'shell = { program = "/usr/bin/fish" }\n'
        s = s.replace("[terminal]\n", "[terminal]\n" + line, 1) if "[terminal]\n" in s else s + "\n[terminal]\n" + line
        open(p, "w").write(s)
    tomllib.loads(s)
PY
```

> [!WARNING]
> **Dos errores de la versión anterior de este bloque:**
> - Borraba `/tmp/clavis-fish-theme` y luego intentaba copiar `examples/matugen.conf` desde ahí; el `|| true` ocultaba el fallo y la plantilla de colores del prompt nunca se instalaba.
> - Añadía una segunda tabla `[terminal]` al final de `alacritty.toml`. El archivo de Omarchy ya tiene una, y una tabla duplicada hace el TOML inválido, así que Alacritty ignoraba toda la configuración.

Registrar la plantilla en `~/.config/clavis/matugen/config.toml`:

```toml
[templates.clavis_fish]
input_path = "~/.local/share/clavis-fish-theme/matugen.conf"
output_path = "~/.config/clavis-fish-theme/colors.conf"
```

### 4.3 Animaciones Elásticas y Borde Activo (Focus Ring)

#### A. Animaciones Niri (`statindet-animations.kdl`)
Crear `~/.config/niri/statindet-animations.kdl` con micro-rebote:

```kdl
animations {
    workspace-switch {
        spring damping-ratio=0.85 stiffness=1000 epsilon=0.0001
    }
    horizontal-view-movement {
        spring damping-ratio=0.85 stiffness=1000 epsilon=0.0001
    }
    window-open {
        duration-ms 500
        curve "cubic-bezier" 0.05 0.9 0.1 1.05
    }
    window-close {
        duration-ms 150
        curve "ease-out-quad"
    }
}
```

> [!WARNING]
> `cubic-bezier` y sus cuatro números son **argumentos separados**. Escribirlos dentro de una sola cadena (`curve "cubic-bezier 0.05 0.9 0.1 1.05"`) hace que `niri validate` rechace el archivo.

Incluir en `config.kdl`:
```bash
sudo -u "$TARGET_USER" bash -c "
grep -q 'statindet-animations.kdl' '$TARGET_HOME/.config/niri/config.kdl' || \
  printf '\ninclude \"statindet-animations.kdl\";\n' >> '$TARGET_HOME/.config/niri/config.kdl'
"
```

#### B. Focus Ring Dinámico con Degradado
Plantilla Matugen para el contorno de ventana:

```toml
[templates.niri_focus_ring]
input_path = "~/.local/share/statindet-niri/niri-colors.kdl"
output_path = "~/.config/niri/statindet-colors.kdl"
```

Contenido de la plantilla `~/.local/share/statindet-niri/niri-colors.kdl`:
```kdl
layout {
    focus-ring {
        active-gradient from="{{colors.primary.default.hex}}cc" to="{{colors.tertiary.default.hex}}cc" angle=135
    }
}
```

Generar los colores **antes** de incluir el archivo (si `statindet-colors.kdl` no existe, `niri validate` falla y niri no carga la configuración):
```bash
WALLPAPER="/ruta/al/wallpaper.jpg"   # el wallpaper activo del usuario objetivo
sudo -u "$TARGET_USER" -H /etc/xdg/quickshell/clavis/scripts/theme/generate_matugen_colors.sh \
  --image "$WALLPAPER" --templates niri_focus_ring
ls -l "$TARGET_HOME/.config/niri/statindet-colors.kdl"
```

Incluir en `config.kdl`:
```bash
sudo -u "$TARGET_USER" bash -c "
grep -q 'statindet-colors.kdl' '$TARGET_HOME/.config/niri/config.kdl' || \
  printf '\ninclude \"statindet-colors.kdl\";\n' >> '$TARGET_HOME/.config/niri/config.kdl'
niri validate -c '$TARGET_HOME/.config/niri/config.kdl'
"
```

## 5️⃣ SPlayer-Next (Reproductor de Música con Letras Sincronizadas)

[SPlayer-Next](https://github.com/SPlayer-Dev/SPlayer-Next) es un reproductor de música moderno para escritorio desarrollado con Electron, Vue 3 y un motor de audio de alto rendimiento en Rust (con decodificación nativa FFmpeg).

### Características Principales:
* **Amplio soporte de formatos**: MP3, FLAC, WAV, AAC, OGG, APE, etc.
* **Letras enriquecidas**: Soporte de formatos LRC / QRC / YRC / TTML con resaltado palabra por palabra (estilo Apple Music) y modo flotante.
* **Visualización de espectro de audio**: Análisis FFT en tiempo real.
* **Integración nativa MPRIS en Linux**: Se integra directamente con los controles multimedia de Clavis Shell, atajos globales de hardware (`playerctl`) y pantalla de bloqueo.
* **Servidores de streaming**: Conexión con bibliotecas Subsonic, Navidrome, Jellyfin y Emby.

### Compilación y Despliegue en el Sistema:

```bash
# 1. Instalar dependencias de compilación
sudo pacman -S --needed --noconfirm pnpm rust cargo clang ffmpeg

# 2. Clonar en el directorio de fuentes /opt/src
SRC_DIR="${SRC_DIR:-/opt/src}"
cd "$SRC_DIR"
if [ ! -d "SPlayer-Next" ]; then
    git clone https://github.com/SPlayer-Dev/SPlayer-Next.git SPlayer-Next
    cd SPlayer-Next
else
    cd SPlayer-Next
    git pull --ff-only
fi

# 3. Compilar aplicación y módulos nativos en Rust
pnpm install
pnpm build:unpack

# 4. Desplegar binarios y recursos en /opt
sudo mkdir -p /opt/SPlayer-Next
sudo cp -a dist/linux-unpacked/. /opt/SPlayer-Next/
sudo chmod 755 /opt/SPlayer-Next/chrome-sandbox
sudo ln -sf /opt/SPlayer-Next/SPlayer-Next /usr/local/bin/splayer-next

# 5. Instalar iconos y entrada de escritorio
sudo install -Dm644 public/icons/favicon-512x512.png /usr/share/icons/hicolor/512x512/apps/splayer-next.png
sudo install -Dm644 public/icons/favicon-256x256.png /usr/share/icons/hicolor/256x256/apps/splayer-next.png
sudo install -Dm644 public/icons/favicon-32x32.png /usr/share/icons/hicolor/32x32/apps/splayer-next.png

sudo tee /usr/share/applications/top.imsyy.splayer_next.desktop <<'EOF'
[Desktop Entry]
Name=SPlayer-Next
Comment=Cross-platform desktop music player with rich lyric support
Exec=/usr/local/bin/splayer-next %U
Icon=splayer-next
Terminal=false
Type=Application
Categories=Audio;Music;AudioVideo;Player;
MimeType=x-scheme-handler/orpheus;audio/mp3;audio/flac;audio/wav;audio/aac;audio/ogg;
StartupWMClass=SPlayer-Next
EOF
```

> [!TIP]
> Una vez instalado, `SPlayer-Next` aparece inmediatamente indexado en el buscador Spotlight de Clavis (`Mod + Espacio`) y en el lanzador de aplicaciones (`Mod + D`). Al reproducir pistas, Clavis muestra automáticamente la portada y los controles de reproducción.
