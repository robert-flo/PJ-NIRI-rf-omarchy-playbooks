Este documento recopila las tipografías oficiales empleadas por **Clavis Shell**, el compositor **Niri**, la terminal **Alacritty** y el entorno en general, detallando los paquetes requeridos, su instalación y su configuración técnica.

---

## 📦 Paquetes y Fuentes Requeridas

| Fuente | Paquete (Arch / AUR) | Uso Principal en el Entorno |
|---|---|---|
| **LXGW WenKai GB Screen** | `ttf-lxgw-wenkai-screen` *(AUR)* | Fuente de interfaz principal (UI) en Clavis Shell, menús y widgets. |
| **JetBrainsMono Nerd Font** | `ttf-jetbrains-mono-nerd` *(Oficial)* | Terminal Alacritty, prompt de Fish, editores de código y glifos Powerline. |
| **Material Symbols Variable** | `ttf-material-symbols-variable` *(Oficial)* | Iconos vectoriales de controles rápidos, barra lateral y centro de control. |
| **Google Sans Flex** | *Integrada en Clavis* | Reloj digital y tipografía display en la barra superior. |

---

## 🛠️ Instalación de Fuentes

Ejecuta el siguiente comando para instalar el conjunto completo de tipografías:

```bash
# 1. Fuentes desde los repositorios oficiales de Arch Linux
sudo pacman -S --needed --noconfirm \
    ttf-jetbrains-mono-nerd \
    ttf-material-symbols-variable

# 2. Tipografía principal de interfaz desde AUR
yay -S --needed --noconfirm \
    ttf-lxgw-wenkai-screen
```

## 🔍 Configuración Interna en Clavis Shell

Clavis Shell define su jerarquía tipográfica en `/etc/xdg/quickshell/clavis/Common/Fonts.qml`:

```qml
// Fragmento de Common/Fonts.qml
readonly property string defaultUi: "LXGW WenKai GB Screen"
readonly property string defaultMono: "JetBrainsMono Nerd Font"
```

> [!TIP]
> **Comportamiento de fuentes en Clavis:**
> Clavis solicita las familias tipográficas de forma explícita (`LXGW WenKai GB Screen` y `JetBrainsMono Nerd Font`), no mediante alias genéricos como `sans-serif` o `monospace`. Esto asegura que la apariencia de la shell sea consistente independientemente de las reglas globales de `fontconfig`.

---

## 💡 Análisis Técnico: Fontconfig y Omarchy

En distribuciones como Omarchy:
- `/etc/fonts/conf.d/50-omarchy.conf` asigna con prioridad estricta:
  - `sans-serif` → Liberation Sans
  - `serif` → Liberation Serif
  - `monospace` → JetBrainsMono Nerd Font
- Debido a esto, un archivo `~/.config/fontconfig/fonts.conf` que busque reemplazar `sans-serif` genérico no afectará a Clavis (que ya pide su fuente explícita) y podría provocar inconsistencias en aplicaciones de terceros.
- Por tanto, la recomendación técnica es **no forzar un `fonts.conf` global**, permitiendo que Clavis use LXGW WenKai y las aplicaciones del sistema mantengan su compatibilidad natural.

## 🔍 Comprobación de Instalación

Verifica que las fuentes están indexadas por el motor de Fontconfig:

```bash
fc-list : family | grep -Ei "LXGW WenKai|JetBrainsMono" | sort -u
```

Salida esperada:
```text
JetBrainsMono Nerd Font
JetBrainsMono Nerd Font Mono
LXGW WenKai GB Screen
LXGW WenKai Mono GB Screen
```
