# 🗄️ Archivos de Sistema de Referencia

> [!NOTE]
> **Navegación:**
> * Anterior: [[05.3 - Guia de Descarga e Integracion de Video (Showcase)|Video Showcase]]
> * Volver a: [[00 - Indice General (MOC)|Índice General]]

`assets/system/` guarda **copias exactas** de los archivos fuera de `$HOME` que deja este playbook, tomadas de la máquina de referencia (2026-10-12). La ruta dentro de `assets/system/` es la ruta absoluta de destino. Sirven para no reconstruirlos copiando bloques de las notas: se instalan tal cual.

> [!IMPORTANT]
> Los archivos de usuario (niri, Clavis, GTK, apps) **no** van aquí: viven en [robert-flo/niri-dotfiles](https://github.com/robert-flo/niri-dotfiles) y se restauran con dotbare ([[03.1 - Dotfiles con dotbare|Dotfiles con dotbare]]). Si cambias un archivo de sistema en la máquina, actualiza su copia aquí y la nota que lo explica.

## 🛠️ Instalación desde el Vault

```bash
VAULT="<ruta-del-vault>"
A="$VAULT/assets/system"

# Respaldo de lo que vaya a reemplazarse
ts=$(date +%s)
for f in /etc/sddm.conf.d/10-theme.conf /etc/sddm.conf.d/99-omarchy-login.conf \
         /usr/local/bin/update-niri-desktop.sh /etc/modprobe.d/i915.conf; do
    [ -f "$f" ] && sudo cp -a "$f" "$f.bak.$ts"
done

# sudoers: validar antes de instalar (un error deja sudo inservible)
for u in gracie niri sura; do
    id "$u" &>/dev/null || continue
    sudo visudo -cf "$A/etc/sudoers.d/04_$u" && \
      sudo install -m 0440 -o root -g root "$A/etc/sudoers.d/04_$u" "/etc/sudoers.d/04_$u"
done
sudo visudo -c

# SDDM
sudo install -Dm644 "$A/etc/sddm.conf.d/10-theme.conf"         /etc/sddm.conf.d/10-theme.conf
sudo install -Dm644 "$A/etc/sddm.conf.d/99-omarchy-login.conf" /etc/sddm.conf.d/99-omarchy-login.conf

# Actualizador diario + timer
sudo install -Dm755 "$A/usr/local/bin/update-niri-desktop.sh"       /usr/local/bin/update-niri-desktop.sh
sudo install -Dm644 "$A/etc/systemd/system/niri-update.service"     /etc/systemd/system/niri-update.service
sudo install -Dm644 "$A/etc/systemd/system/niri-update.timer"       /etc/systemd/system/niri-update.timer
sudo systemctl daemon-reload && sudo systemctl enable --now niri-update.timer

# Solo Intel con parpadeo (ver 04.1): requiere regenerar el UKI
sudo install -Dm644 "$A/etc/modprobe.d/i915.conf" /etc/modprobe.d/i915.conf
sudo mkinitcpio -P
```

> [!NOTE]
> `/etc/sddm.conf.d/10-theme.conf` pertenece al paquete `omarchy-settings`, pero está marcado como archivo de configuración (`backup`): las actualizaciones conservan la versión modificada y, si Omarchy lo cambia, dejan un `10-theme.conf.pacnew`. Además `99-omarchy-login.conf` repite `Current=catppuccin-mocha-mauve` y, al leerse después, prevalece.

> [!WARNING]
> El tema `catppuccin-mocha-mauve` debe existir en `/usr/share/sddm/themes/` antes de instalar los `.conf` de SDDM (lo instala [[01.2 - Paso 2 - Creacion de Usuario y Login SDDM|01.2]]). Si falta, SDDM cae a su tema por defecto.

## 🔍 Comprobar que la máquina coincide con el Vault

```bash
A="<ruta-del-vault>/assets/system"
( cd "$A" && find . -type f | sed 's|^\.||' ) | while read -r f; do
    sudo cmp -s "$A$f" "$f" && echo "igual     $f" || echo "DISTINTO  $f"
done
```
