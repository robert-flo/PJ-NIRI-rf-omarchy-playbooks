## 🛠️ Recreación Exacta de las Fuentes

Para clonar los tres componentes core en los mismos commits que se instalaron el 2026-10-12 (para seguir actualizando, quédate en `personal` en lugar de fijar el commit):

```bash
BUILD_DIR="${BUILD_DIR:-/opt/src}"
sudo mkdir -p "$BUILD_DIR" && sudo chown "$USER:$USER" "$BUILD_DIR"
cd "$BUILD_DIR"

clone_fork() {  # <dir> <fork> <upstream> <commit>
    git clone -b personal "https://github.com/robert-flo/$2.git" "$1"
    git -C "$1" remote add upstream "https://github.com/StatIndet/$3.git"
    git -C "$1" remote set-url --push upstream DISABLE
    [ -n "${4:-}" ] && git -C "$1" checkout "$4"
}

clone_fork niri-edge  PJ-NIRI-fo-niri-edge niri-edge  74f1abfb
clone_fork quickshell quickshell           quickshell 920f335
clone_fork key-cli    PJ-NIRI-fo-key-cli   key-cli    099621d
```
