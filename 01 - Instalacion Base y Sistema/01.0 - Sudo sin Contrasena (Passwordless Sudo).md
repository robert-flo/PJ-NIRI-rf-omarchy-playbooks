# 🛡️ Configuración Permanente de Sudo sin Contraseña

> [!NOTE]
> **Navegación:**
> Volver a: [[00 - Indice General (MOC)|Índice General]] | Siguiente: [[01.1 - Paso 1 - Instalacion de niri-edge y key-cli|Paso 1: Instalación de niri-edge y key-cli]]

Este playbook documenta y automatiza la concesión de privilegios administrativos completos (`sudo`) sin solicitar contraseña de forma persistente. Está especialmente optimizado para **Arch Linux**, **Omarchy** y sistemas con `systemd`.

---

## 🎯 Objetivo

Garantizar que el usuario deseado ejecute comandos con privilegios administrativos (`sudo`) sin interrupciones ni solicitudes de contraseña:
1. Eliminar temporizadores automáticos que revocan privilegios tras 15 minutos.
2. Resolver de raíz los bloqueos generados por herramientas y scripts del sistema que invocan `sudo -v` (como `omarchy-update` y demonios de mantenimiento).

---

## ⚠️ Diagnóstico: El Caso Borde de `sudo -v` y `verifypw`

En distribuciones como Arch Linux y Omarchy, es común encontrar dos inconvenientes con la configuración convencional de `sudo`:

1. **Reglas volátiles:** Utilidades como `omarchy-sudo-passwordless` generan directivas temporales asociadas a timers de `systemd` que expiran en periodos cortos.
2. **El bloqueo con `sudo -v` (`verifypw`):**
   - Aunque se defina `USUARIO ALL=(ALL) NOPASSWD: ALL`, si existen otros archivos dentro de `/etc/sudoers.d/` (por ejemplo, `50-asdcontrol`) con reglas restrictivas, la directiva global predeterminada de `sudo` suele ser `verifypw = all`.
   - Cuando un script automatizado valida credenciales con `sudo -v` (como `omarchy-update-stay-awake`), `sudo` intentará comprobar la contraseña contra todas las reglas coincidentes, solicitando la clave e interrumpiendo procesos desatendidos.

> [!IMPORTANT]
> **Solución técnica definitiva:**
> Se requiere declarar explícitamente en el archivo de sudoers tanto el bypass de contraseña como la directiva de verificación flexible:
> ```sudoers
> <USUARIO> ALL=(ALL) NOPASSWD: ALL
> Defaults:<USUARIO> verifypw = any
> ```

## 🤖 Directiva para Agentes de Automatización

Si proporcionas esta tarea a un agente autónomo o asistente de línea de comandos en un nuevo entorno:

```text
Configura el usuario objetivo para que cuente con privilegios permanentes de sudo sin contraseña (passwordless sudo).
Pautas obligatorias:
1. Detecta dinámicamente el usuario con ${TARGET_USER:-${SUDO_USER:-$USER}}.
2. Escribe el archivo en /etc/sudoers.d/04_${TARGET_USER}.
3. Incluye las dos directivas indispensables para evitar bloqueos con 'sudo -v':
   <USUARIO> ALL=(ALL) NOPASSWD: ALL
   Defaults:<USUARIO> verifypw = any
4. Fija permisos estrictos 0440 en el archivo.
5. Valida la integridad sintáctica con 'visudo -c'.
6. Comprueba que 'sudo -k && sudo -n whoami' y 'sudo -n -v' retornen código de salida 0.
```

## 🛠️ Ejecución Automatizada (Script Idempotente)

El siguiente script es reutilizable para cualquier usuario y puede ejecutarse de forma segura:

```bash
sudo bash -c '
set -euo pipefail

# Variable parametrizada: Toma el primer argumento, o el usuario que invocó sudo, o el usuario actual
TARGET_USER="${1:-${SUDO_USER:-$USER}}"
FILE="/etc/sudoers.d/04_${TARGET_USER}"

echo "==> Configurando passwordless sudo para: ${TARGET_USER}"

cat <<EOF > "$FILE"
${TARGET_USER} ALL=(ALL) NOPASSWD: ALL
Defaults:${TARGET_USER} verifypw = any
EOF

# Asignar permisos obligatorios para sudoers
chmod 0440 "$FILE"

echo "==> Validando sintaxis con visudo..."
visudo -c

echo "==> Verificando ejecución no interactiva..."
sudo -u "$TARGET_USER" -k
sudo -u "$TARGET_USER" -n whoami > /dev/null
sudo -u "$TARGET_USER" -n -v > /dev/null

echo "✅ Configuración completada exitosamente para ${TARGET_USER}."
' -- "${1:-$USER}"
```

> [!WARNING]
> **Pegar el script con sangría rompe sudoers.**
> Si la terminal añade espacios al inicio de cada línea al pegar, el `EOF` de cierre deja de reconocerse y el resto del script termina escrito dentro de `/etc/sudoers.d/04_<usuario>`. `sudo` sigue funcionando, pero muestra errores de sintaxis en cada uso. Para evitarlo, escribe primero el archivo en uno temporal y valídalo antes de instalarlo:
> ```bash
> tmp=$(mktemp)
> printf '%s\n' "$USER ALL=(ALL) NOPASSWD: ALL" "Defaults:$USER verifypw = any" > "$tmp"
> sudo visudo -cf "$tmp" && sudo install -o root -g root -m 0440 "$tmp" "/etc/sudoers.d/04_$USER"
> rm -f "$tmp"
> ```

> [!TIP]
> Puedes especificar un usuario concreto pasando su nombre como argumento:
> ```bash
> sudo ./configurar-sudo.sh mi_usuario
> ```

## 🔍 Pasos de Verificación Manual

Comprueba el correcto funcionamiento mediante los siguientes comandos:

1. **Prueba de validación no interactiva (`sudo -n -v`):**
   ```bash
   sudo -k && sudo -n -v
   ```
   *Debe salir inmediatamente con código 0 y sin pedir contraseña.*

2. **Ejecución como superusuario en modo no interactivo:**
   ```bash
   sudo -n whoami
   ```
   *Salida esperada:* `root`.

3. **Auditoría de sintaxis en `/etc/sudoers.d/`:**
   ```bash
   sudo visudo -c
   ```
   *Cada archivo evaluado debe responder con `... parsed OK`.*
